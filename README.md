# Premium Drones Georgia

განახლებული სტატიკური საიტი: ქართული, ინგლისური და რუსული გვერდები, P150 MAX, სერვისი, აკადემია, გალერეა, ბლოგი, საკონტაქტო ფორმა და კალკულატორი.

## სწრაფი განთავსება

`dist/` უკვე შეიცავს გასაშვებად მზად საიტს. გადაიტანეთ **ამ საქაღალდის შიგთავსი** თქვენი ჰოსტინგის საჯარო დირექტორიაში. npm, აწყობა, მონაცემთა ბაზა და API გასაღებები არ სჭირდება. მთავარი გვერდები: `/`, `/en/`, `/ru/`.

Docker-ის შემთხვევაში პროექტის ფესვში გაუშვით:

```sh
docker compose up -d --build
```

საიტი მოემსახურება `127.0.0.1:8102`-ს. არსებული HTTPS პროქსი მიმართეთ ამ პორტზე. პორტი 8101 განზრახ არ გამოიყენება, რადგან იქ არსებული პროტოტიპია. SSL სერტიფიკატი და DNS თქვენს ჰოსტინგში უნდა იყოს გამართული.

ლოკალური დათვალიერებისთვის, პროექტის ფესვში:

```sh
python -m http.server 8000 --directory dist
```

გახსენით `http://localhost:8000/`. `file://` რეჟიმის ნაცვლად გამოიყენეთ HTTP სერვერი: რესურსების ბმულები ჰოსტინგის ფესვიდან იწყება.

## კონტენტის შეცვლა

- ქართული მთავარი გვერდი: `dist/index.html`.
- ქართული დამატებითი გვერდები: `scripts/page-bodies.html`.
- ინგლისური და რუსული თარგმანები: `dist/assets/js/content.js`.
- სტილი: `dist/assets/css/style.css`.
- ინტერაქციები: `dist/assets/js/script.js`.
- შრიფტები და ლიცენზიები: `dist/assets/fonts/`.
- საიტის ლოგო და რეალური ფოტოები: `dist/assets/img/`.

ქართული ტექსტი შეცვალეთ UTF-8 რედაქტორით. დამატებითი გვერდებისა და თარგმანების განახლების შემდეგ, განვითარების გარემოში საჭიროა Python და `lxml`:

```sh
python scripts/build-pages.py https://premium-drones.ge
node --check dist/assets/js/content.js
node --check dist/assets/js/script.js
python scripts/verify-site.py
```

ეს გენერაცია ჰოსტინგზე საჭირო არ არის — განთავსდება უკვე მზად `dist/`.

## ფორმა და არსებული ბექენდი

საკონტაქტო ფორმა ამოწმებს ველებს და ხსნის მომზადებულ წერილს მომხმარებლის ელფოსტის პროგრამაში. წერილს მომხმარებელი თავად აგზავნის. საიტი განაცხადს სერვერზე არ ინახავს და გაგზავნის წარმატებას არ ადასტურებს. ტელეფონი, ელფოსტა და WhatsApp პირდაპირი ბმულებითაც ხელმისაწვდომია.

მოწოდებული RAR შეიცავდა სტატიკურ პროექტს. მისი `PROJECT_MEMORY.md` ცალკე FastAPI/SQLite პროექტს (`C:\Projects\PDGE-Site`) აღწერს, მაგრამ ამ პროექტის კოდი არქივში არ იყო. ადმინ პანელი, ონლაინ მაღაზია, სერვერული განაცხადები და შეტყობინებების გაგზავნა ამ პაკეტში არ არის აღდგენილი. ამ დიზაინის იმ სისტემასთან დასაკავშირებლად საჭიროა შესაბამისი ბექენდის პროექტი.

## შემოწმება

დასრულებულია სტატიკური გვერდების, რესურსების, შიდა ბმულების, თარგმანების, შრიფტების ლიცენზიებისა და JavaScript-ის სინტაქსის შემოწმება. ცალკე DOM ტესტებით შემოწმებულია ნავიგაცია, ენების გადართვის ბმულები, თემები, გალერეა, ფორმის ვალიდაცია და კალკულატორი. ბრაუზერში რეალური ვიზუალური შემოწმება ამ გარემოში ხელმისაწვდომი არ იყო; გთხოვთ, საბოლოო განთავსებისას გადაამოწმოთ 390 px და 1200 px ხედები.

განთავსების პაკეტში საწყისი RAR-ის ტექნიკური ჩანაწერები, კერძო ფაილები, git-ის ისტორია და გამოუყენებელი მასალები საჯარო დირექტორიაში არ შედის.
